# Failure Taxonomy (失敗分類學)

為了系統化修補模型的泛化能力，我們將 Validation 中預測失敗的樣本分為以下 8 大類，並放入對應的資料夾中進行分析與後續補料計畫：

- **`false_negative` (道路漏抓)**: 畫面中明顯是道路，但模型沒有抓到 (Recall 偏低)。
- **`under_segmentation` (覆蓋不足)**: 道路有抓到，但 Mask 的範圍沒有完全包覆真實道路區域 (通常出現在遠端或邊界)。
- **`boundary_collapse` (邊界破碎)**: 抓到的道路邊緣呈現破碎、鋸齒狀，或者對於直線的邊緣掌握度極差。
- **`over_segmentation` (過度分割)**: 吃到不屬於道路的區域，例如：草地、人行道、路肩、建築物。
- **`shadow_confusion` (陰影誤判)**: 受到樹影、車影或建築陰影干擾，導致模型無法辨識陰影下的道路，或將陰影本身誤判為邊界。
- **`perspective_failure` (遠端收斂崩潰)**: 畫面下半部 (近端) 表現正常，但在道路延伸至消失點 (Top Region) 的區域發生結構性誤判或斷裂。
- **`temporal_flicker` (前後幀跳動)**: (針對影片連續幀) 在單張圖片看似合理，但在時間軸上 Mask 發生劇烈的閃爍或形狀突變。
- **`label_noise` (標註雜訊)**: 預測結果其實是合理的，但因為人工標註 (Ground Truth) 本身的錯誤、邊界不一致或漏標，導致被系統判定為失敗。
