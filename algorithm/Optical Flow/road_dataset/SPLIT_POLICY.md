# 資料切分政策

## 規則

必須依場景、路段或影片片段切分。不要把相鄰影片影格隨機分散到 train、validation 與 test。

## 建議配置

```text
scene_01 -> train
scene_02 -> train
scene_03 -> val
scene_04 -> test
```

## 原因

同一段連續影片的相鄰影格高度相似。若同時出現在 train 與 validation，驗證分數會過度樂觀，無法真正反映泛化能力。

## 驗證集覆蓋

驗證集應刻意包含困難條件：

- 陰影。
- 夜間場景。
- 雨天或濕滑路面。
- 斑馬線。
- 車道標線。
- 路邊停車。
- 不同相機高度。
- 強反射。
- 破損路面。
