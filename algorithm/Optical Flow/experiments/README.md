# Experiments

This directory is used to store experiment configurations and results for the MLOps research workflow.

Each experiment should ideally be stored in its own subdirectory (e.g., `exp_001_classical/`) and contain:
- `config.json` (Experiment configuration)
- `metrics.csv` (Frame-by-frame or image-by-image metrics)
- `summary.json` (Aggregated summary metrics)
