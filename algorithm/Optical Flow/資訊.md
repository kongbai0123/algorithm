目前專案聚焦在 PC 端道路面辨識驗證，核心任務是建立穩定、可解釋、可量測的道路面遮罩。

任務定義如下：

```text
Road Surface Segmentation
```

## 目前主程式

目前主入口已統一為：

```text
run_road_pipeline.py
```

目前主流程以 `classical` baseline 為基準，也支援 `fused`、`yolo-seg` 與 `yolo-seg-fused`。  
整體流程如下：

```text
input image / video
-> 道路顏色 / 位置 / 邊緣分數
-> 視角走廊先驗
-> row-wise road envelope
-> GrabCut refinement
-> 側向道路補回
-> 保留最大且與底部連通的區塊
-> 產生 mask / overlay / metrics
```

現階段 `classical` 仍可作為 baseline，但不應該是最終方案。較合理的路線是：


## 光流方法狀態

目前已納入 Horn-Schunck 為可解釋的 dense optical flow 基準，並保留其他方法供比較：

| 方法 | 性質 | 目前定位 |
| --- | --- | --- |
| Horn-Schunck | 傳統稠密光流 | 可解釋基準，適合報告與比較 |
| Farneback | OpenCV 傳統稠密光流 | 適合影片與道路 ROI 運動統計 |
| Lucas-Kanade | 傳統稀疏光流 | 適合在道路 ROI 追蹤特徵點 |

目前不直接把 RAFT、GMFlow、FlowFormer 放進主流程，而是保留為未來 benchmark 或研究比較方向。
